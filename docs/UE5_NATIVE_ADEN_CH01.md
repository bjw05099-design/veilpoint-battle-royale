# 아덴 CH01 Unreal Engine 빌드

Unreal Engine 5.8의 `CH01_Aden`이 스토리 Windows 개발 패키지의 시작 레벨이다.
기존 `CH01_Coast`는 별도의 네이티브 자동 회귀 레벨로 사용한다.
스토리와 배틀로얄은 별도로 출시한다.

## 플레이 구간

`CH01_Aden`에는 공개 아덴 지형 70타일, 도로 중심선 183개, 일반 건물 외곽
4,865개가 원본 배치로 들어간다. CRS는 EPSG:32638이고 Unreal에서 1m는
100cm다. 표고 격자의 샘플 간격은 32m다. 서쪽에 512m 타일 21개를
추가해 5.120 × 3.584km 경계까지 보행 지형과 충돌을 생성한다. 서쪽
5.505㎢는 표고 기반 지형이며 도로·건물 레이어는 기존 등록 구역에서 제공한다.
도로·건물 외곽의 색띠는 출처를 읽는
표현이다. 건물의 높이와 내부는 조사 범위에 속하지 않는다. 외곽의
보행 제한은 렌더하지 않는 게임용 충돌이다. 1인칭 지표의 양면 재질은 등록 원본의
도로·건물 색과 고도 기반 지표색을 사용한다. 요철과 표식 표현은 게임의
지도 레이어이며 측량된 외장 재질은 아니다. 2015년 아덴 전체 배치와
도시 전체 보행 경험을 검증해야 한다.

배경에는 같은 GLO-30 원본에서 추출한 40.96 × 35.84km 표고를
5.12km 크기의 3D 구역 56개로 렌더한다. 보행 구역 주변은 기존 256m
표고 격자를 유지한다. 먼 구역은 원본 격자의 높이와 대조해 기본 삼각형
근사 오차가 6m 이하일 때 512m 또는 1,024m 간격을 사용한다. 정밀도가
다른 구역의 경계는 더 촘촘한 쪽과 같은 정점을 사용한다. 보행 지형과
맞닿는 68개 경계 구간은 32m 간격의 정점 544개를 공유한다. 낮은 곳과
급경사는 표고와 경사에 따라 다른 색으로 표시한다. Windows 패키지 검사는
광역 구역 경계 97곳을 비교한다. 보행 충돌은 위의 70타일 구역에 적용된다.

보행 구역의 도로 중심선과 건물 외곽 표식은 지표 삼각형 경계에서
나뉘어 경사에도 같은 간격으로 붙는다. Windows 패키지 검사는
표식의 그려진 면과 지형 사이 오차를 측정하고 거리 화면을 저장한다.
도로가 꺾이는 곳은 기존 중심선 양옆의 표식 폭 안에서 모서리를 채운다.
검사는 도로 모서리에도 같은 오차 기준을 적용한다.
등록된 일반 건물 외곽선 4,865개의 내부는 원본 경계에 맞춘
지표 면으로 채워 도로와 건물 부지를 구분한다. 건물 높이 자료가
등록되지 않은 이 구역에서는 지표에서 부지의 범위를 볼 수 있다.
지표 표식은 최대 49개 512m 구역의 독립 메시로 들어가 엔진이
화면 밖 구역을 개별적으로 생략할 수 있다. 부지 경계 충돌은 지형
삼각형 교차점마다 나눈 뒤 512m 구역별로 분리한다. Windows 진단은
원본 경계의 양방향 충돌, 지표에 맞춘 경계 하단의 높이, 구역을
가로지르는 벽의 양쪽 충돌을 검사한다.
보행 지표는 512m 렌더 구역 70개의 독립 메시로 그린다. 경계의 위치,
노멀과 색은 같은 격자에서 가져온다. 서쪽 접속부에서 두 표고 텍스처가
기존 세계 좌표를 공유한다. 123개 렌더 경계와 양쪽의 충돌을 검사하고,
기존 지역에서 서쪽으로 이어지는 1.024km 구간은 실제 캡슐을 스윕한다.
고도와 경사를 기준으로 지표색을 조정해 평지와 급경사의 윤곽을 구분한다.
근거리 지면은 2.56m 단위로 이어지는 노멀·거칠기·색 변화 텍스처를
사용한다. 카메라에서 65m 떨어지면 기본 지형색과 광역 텍스처가 이어진다.
지도 표지와 구조물은 공유 표면 텍스처에 거칠기·금속성·색 변화 값을
적용해 도장면, 노출 금속, 풍화된 표면으로 구분한다.

경사 보행은 바닥 접촉과 진행 방향을 사용한다. 출발하거나 방향을
바꿀 때는 저속 구간에서 입력 가속도를 반영한다. 아덴 지표에서
공중이나 다른 바닥으로 넘어가면 기본 속도 배율로 돌아온다.

현장 지도 안에서 마우스 오른쪽 버튼을 누른 채 끌어 같은 축척으로
지도를 이동한다. 방향키로도 이동하고 Home으로 플레이어 중심 보기에
돌아온다. 왼쪽 클릭은 지면 위치에 개인 핀을 찍는다.
**H**로 등고선 레이어를 켜고 끈다. 확대 보기에는 20m 간격, 넓은
보기에는 100m 간격을 표시한다. 등고선은 아덴과 서쪽 확장 구역의
보행 지형 삼각형에서 계산하며, 범례에는 선택한 핀의 지면 표고가
표시된다. 패키지 검사는 양쪽 구역의 등고선에 대해 지면 충돌 표고와
지도 경계를 확인한다.

새 캠페인은 **5분짜리 오프닝 17개 컷**으로 시작한다. 첫 자막은
**“아덴, 예멘 남부 | 2015년”**이다. 예멘 정부 수반 만수르 알하림과
반군 지도자 압둘 카림 알하디르의 가상 뉴스 발표, 내전 거리, 구금과
구호 인력 피랍, 유엔 긴급회의를 배경으로 이수혁의 독백이 흐른다.
한국의 파견 브리핑이 끝나면 아덴만에서 승선해 아덴에 내릴 때까지 이수혁의 1인칭으로
이어진다. 마지막 시야가 CH01 플레이 카메라와 맞물리면서 첫 무전과
함께 조작이 열린다. ESC로 일시 정지할 수 있다. 이어하기는 저장한
지점에서 시작한다.

독백은 임시 한국어 합성 음원 10개와 두 구절씩 나뉜 자막으로 구성된다.
Unreal 저작 중에 독백과 환경음 17개를 SoundWave로 가져와 맵에 연결한다.
선박, 임시 접안대, 방송, 구금, 회의 및 브리핑 세트는 컷신에서 사용한다.

WASD와 마우스로 움직인다. F로 무전과 장치를 작동하고, 1·2로 정규군과
합류할 길과 연락 방법을 고른다. CH02 합류로, CH05 전초, CH11 중계소
교전에서는 왼쪽 클릭으로 발사하고 R로 장전한다. 서버가 발사나 충돌을
처리하면 화면 중앙에 짧게 표시하고, 상대에게 피해를 준 경우 X 표시를 띄운다. 상대가 시야를 잡으면
공격하므로 엄폐하고, 다시 시작하려면 F7을 누른다. 교전이 끝나면 F로
지점을 확보한다. 공개 방송을 선택하면 최종 중계소에 상대가 2명,
전령을 선택하면 1명 나타난다. CH04·CH08·CH09는 접선 지점에 이르면
진행한다. 남은 동행 장면은 네 곳이다.

장치 근처에서 시야를 유지한다. 동행자는 15m 이상 벌어지면 기다린다.
동선은 등록된 공개 도로 39개 경로 조합으로 이어진다. 한국어 대사는
패키지에 포함되는 자막 서체를 사용한다.
[12장 대본과 엔딩](ADEN_CAMPAIGN_SCREENPLAY_KO.md)

빌드용 공개 데이터 제공처는 [Copernicus GLO-30](https://registry.opendata.aws/copernicus-dem/)과
[OpenStreetMap 기여자](https://www.openstreetmap.org/copyright)다. 표고 제품과
도로·건물 DB의 원본 라이선스 및 출처는 [아덴 자료 빌드](ADEN_PUBLIC_SOURCE_BUILD.md)에 있다.

## 현장 지도와 후속 장면

M 키는 현장 지도 → 광역 표고 → 1인칭 화면 순서로 바뀐다. 현장
지도에서 휠로 확대하고 방향키로 시야를 옮긴다. Home을 누르면 내 위치로
돌아온다. 지도를 보는 동안 WASD와 마우스는 캐릭터를 움직이지 않는다. 축소하면
서쪽 지형까지 표시되고 점선이 기존 도로·건물 자료 구역의 서쪽 경계를 보여준다.
P는 현장 지도 중앙의 실제 지면에 개인 핀을 놓고 Delete는 핀을 지운다.
1인칭에서는 가까운 핀이 시야에 들어올 때 거리와 함께 보인다.
현재 경로가 있으면 G 키로 플레이어와 경로 전체, 목표를 한 화면에
맞춘다. G를 다시 누르면 이전 현장 지도 중심과 확대 수준으로 돌아간다.
CH02와 CH07에서 F로 선택지를 연 뒤 현장 지도의 1·2로 두 경로를
미리 비교할 수 있다. 미리보기에서 각 구간의 경로 길이를 확인하고
1인칭으로 돌아와 1·2를 누르면 선택이 확정된다.
현장 지도의 거리 격자와 축척은 확대 단계에 맞춰 바뀐다.
3단계 이상 확대하면 지표 그림 위에 원본 도로 중심선과 일반 건물 외곽을
화면 좌표에 맞춰 다시 그린다. 화면에 걸친 구역의 선분만 골라 경계에서
자르므로 최대 확대에서도 도로와 부지의 형태를 읽을 수 있다.
확대 화면 바깥의 현재 목표는 가장자리 화살표로 이어진다. 플레이어 표식은
카메라를 위아래로 움직여도 수평 방향을 유지한다.
지도에는 플레이어, 현재 목적지와 동행자가 표시된다. 광역판은 40.96 ×
35.84km의 표고와 확장된 보행 구역을 표시한다. 지역별 실측 범위와
클리핑은 Unreal 월드 센티미터에 맞춘다.

J는 플레이 중 고른 경로와 연락 결과, 최근 교신 최대 세 줄을 보여준다.
체크포인트에서 재개하면 복귀한 장면의 교신부터 다시 기록한다. F6으로 저장하고
F7으로 현재 체크포인트의 시작 지점으로 돌아간다. 신호 남은 시간,
분기와 완료 상태를 저장한다. 예전 버전 1–7은 대응하는 장면의 시작으로
옮긴다. 저장값이 깨졌다면 검증을 통과한 백업으로 복귀한다.
F9는 1인칭 상태의 애플리케이션 프레임 시간을 로컬에서 기록하며
ESC 메뉴와 지도는 측정에서 제외한다.

## 실제 Unreal 저작과 실행 증거

`scripts/prepare-native-ch01-win64.ps1 -EngineRoot <설치된_UE_5.8> -PackageNative`
는 Unreal Editor C++ 모듈을 컴파일하고 레벨과 재질을 작성한다.
레벨을 다시 읽고 모드, 원본 데이터 액터, 재질 참조 및 맵 해시를 검사한다.

`author-package`로 이어서 빌드한 Windows 실행 파일은 기본 레벨에 직접
진입한다. 별도 진단 저장 슬롯에서 두 대표 경로를 CH12까지 실행하며,
실제 아덴의 캡슐 스윕, 동행자가 기다리는 거리, 셔터 조작 중 이탈,
교전의 사격·피해·재개, 신호등 경고와 분기, 한국어 폰트 패키징과
이전·손상된 저장 복귀를 검사한다. 오프닝에서는 카메라 컷 17개의 PNG와 300초 분량,
패키지의 음원 참조, 입력 차단과 마지막 컷의 조작 복귀를 검사한다.
12시간 본편 분량과 음성·실사 자산, 사람의 실기 검증 및 QHD 성능은
별도의 완료 기준이다.

자동 검사에서는 1인칭, 현장 지도, 광역 지도, 후속 장면을
Unreal에서 PNG로 직접 렌더하고 1인칭 화면의 지표 픽셀을 검사한다. Windows의 검증 기록에는 이 이미지와
경로·저장 증거가 남는다. 아덴 검사를 통과한 Windows 후보는
`latest-aden-candidate.json`에 기록된다. 기존 해안 개발 맵의 창 모드
검사는 별도로 실행한다.

서체는 Noto Sans CJK KR을 프로젝트 자막 문자에 맞게 줄이면서 이름을
바꾼 SIL OFL 1.1 파생본이다. 원 저작권과 배포 조건은
[서체 라이선스](../Unreal/Veilpoint/Content/StoryFonts/OFL.txt)에 있다.
`python scripts/build-aden-dialogue-font.py`로 자막 문자 누락을 확인한다.
