# VEILPOINT Windows 검증 대기 목록

## 빌드 대상

- 직전 Windows 성공본은 `95b9d8d7840d8045a5c5898ceec015a866c852f7`이다. 이 패키지는 아덴 보행과 기능 회귀를 확인할 때 사용한다.
- 이번 빌드 대상은 `71c154eac1b90f1fbd7d1a528268a90c4375ad0a`이다. 기존 아덴 충돌 구역, 12장 연결과 저장 복구, 5분 오프닝, 총기 시제품, 젖은 지면과 배틀로얄 준비 상태를 포함한다. 이전 대기 항목인 개인 핀, 조준 전환, 분기 경로 길이와 배틀로얄 배속 재생을 함께 검사한다. 이번 회차의 아덴 경사 보행과 경로 복귀, CH02 분기별 장비, 배틀로얄 준비 단계 장비 선택을 포함한다. 총기 모델은 M4A1과 AKM이다. 새 지도 포인터 조작, 발걸음·착지 반응, 교전 종료 무전과 배틀로얄 연속 재생까지 포함한다. 등록된 도로 분류에 따른 월드·지도 표시, 체크포인트 지면 검사, 목표 상호작용 안내, 총기와 벽 사이의 시각 처리, 경기 시간 표시까지 포함한다. 이번 후보에는 아덴 지도 핀 3개 저장과 복구, 셔터·통행 장치의 이동 충돌, 경기 중 배틀로얄 지도도 포함한다. 이번 후보에는 아덴 지면의 근거리 표면 재질, 스토리 장 전환 안내, 배틀로얄 본인 이벤트 타임라인을 추가했다.
- **상태는 시작 지시 대기.** PC에서 실행기 창이 닫혀 있다면 `START_BUILD_PC.cmd`로 연다. 처음 보이는 `Listening for Jobs`와 전용 저장소 Actions의 활성 작업을 확인한다. 이미 진행 중인 작업은 종료 결과부터 확인한다.

시작 지시가 오면 아래 요청으로 전용 Windows 실행기에 `author-package` 한 건을 넣는다. 이 작업에서 사전 점검, C++ 컴파일, 레벨 저작, 패키징과 실행 검사를 차례대로 수행한다. 실행 전 게임 저장소 `main`이 앞섰다면 이 기준점 이후의 변경을 먼저 확인해 빌드 대상을 확정한다.

```json
{
  "schema": "veilpoint-pc-build-v1",
  "source_sha": "71c154eac1b90f1fbd7d1a528268a90c4375ad0a",
  "operation": "author-package"
}
```

## 패키지가 나온 뒤 직접 확인할 것

1. 검증된 새 패키지의 `PLAY_VEILPOINT.cmd`로 실행한다. 기존 저장을 옮기기 전에 첫 화면부터 한 번 재생한다. **이수혁 독백의 발음과 자막 싱크, 음량, ESC 일시 정지·재개, 배에서 내린 뒤 마우스와 WASD가 바로 동작하는 순간**을 확인한다. 자동 오프스크린 검사는 음소거 상태이므로 청취 검사는 직접 한다.
2. CH01에서 F 상호작용과 F7 복귀를 시험한다. M 현장 지도에서 최대 확대, 방향키 이동과 Home 복귀, P 배치와 Delete 삭제를 확인한다. 1인칭에서 가까운 핀이 벽에 가려지면 표시가 사라지는지 본다. 표시된 길을 따라가다가 24m 이상 벗어나 M 지도에서 복귀 방향 점선과 거리를 확인한다. 아덴 지면을 가까이에서 보고 행군 중 거리 전환과 기존·서쪽 구역 접합부의 표면을 비교한다. 같은 아덴 경사면을 오르내리며 속도 전환, 방향 반전, 평지 복귀, 앉아서 이동하는 감각을 확인한다. 휠 확대 시 커서가 가리킨 위치를 유지하는지와 클릭한 지점의 핀이 맞는지 확인한다. 달리기에서 앉기로 전환할 때 발소리가 갑자기 겹치는지, 점프 후 착지 때 화면 시점은 유지되고 장비만 내려갔다 돌아오는지 확인한다. F 목표에 가까이서 시선을 돌리거나 가려진 접근로에서 거리·방향·막힘 안내를 확인한다. 셔터 밑으로 이동해 상승 또는 닫힘이 멈추는지와 물러났을 때 동작이 이어지는지 본다. 지도에서 B로 핀 슬롯 1·2·3을 바꾸며 각각 저장하고, 게임을 재실행해 저장 복구를 확인한다. J로 교신 기록도 확인한다.
3. CH02와 CH07의 선택지에서 M과 1·2로 두 길의 표시와 길이를 확인한 뒤 1인칭에서 선택을 확정한다. CH02 교전에서 1인칭 총기, 우클릭 조준, 벽 앞 총기 내림과 벽에서 물러났을 때의 복귀를 확인한다. 빈 탄창과 탄이 남은 탄창의 재장전 동작, 탄약 표시, 과열과 냉각도 비교한다. M4A1의 어두운 개머리판과 AKM의 목재·곡선 탄창 실루엣을 비교한다. F7 복귀 후 HUD의 이름과 장착한 모델이 일치하는지 확인하고 두 모델을 각각 화면에 캡처한다.
4. 배틀로얄 로컬 호스트·클라이언트에서 V로 M4A1과 AKM을 전환해 모델명과 탄약 표시를 보고, Enter로 준비한 뒤 V가 잠기는지 확인한다. 두 참가자의 시작 전 보급품 보존, 준비 확인 표시와 엄폐 판정도 확인한다. 경기 중 M으로 지도를 열어 건물, 안전구역, 본인 위치와 가운데 버튼 표식을 확인한다. 경기 후 M으로 본인 이동 기록을 열어 T로 1·3·6배속을 바꿔 본다. 재생 중 Space로 일시 정지했다가 같은 시점에서 재개하고, Shift+방향키로 15초 이동한다. 관측 사이의 표시가 연속적이며 기록 공백에는 이동선을 잇지 않는지 확인한다. Page Up·Page Down으로 본인의 안전구역 이탈·복귀와 경기 결과 시점을 이동한다.

키보드·마우스와 청취 확인은 자동 패키지 검사와 별도로 기록한다. BR의 로컬 검증 결과는 실제 인터넷 참가자와의 대전 결과와 구분한다.
