# VEILPOINT Windows 검증 대기 목록

## 빌드 대상

- 직전 Windows 성공본은 `95b9d8d7840d8045a5c5898ceec015a866c852f7`이다. 이 패키지를 아덴 보행과 QHD 프레임 시간 비교의 기준으로 보관한다.
- 이번 빌드 대상은 `3e984064fd740b5bfd3c68bcc30296c72c508600`이다. 아덴 충돌 구역 분할, 스토리의 12장 연결과 교전, 5분 오프닝과 2015년 아덴 첫 자막, 배틀로얄 로비 변경이 모두 들어 있다.
- **상태는 시작 지시 대기.** PC에서 실행기 창이 닫혀 있다면 `START_BUILD_PC.cmd`로 연다. 처음 보이는 `Listening for Jobs`와 전용 저장소 Actions의 활성 작업을 확인한다. 이미 진행 중인 작업은 종료 결과부터 확인한다.

시작 지시가 오면 아래 요청으로 전용 Windows 실행기에 `author-package` 한 건을 넣는다. 이 작업에서 사전 점검, C++ 컴파일, 레벨 저작, 패키징과 실행 검사를 차례대로 수행한다. 실행 전 게임 저장소 `main`이 앞섰다면 이 기준점 이후의 변경을 먼저 확인해 빌드 대상을 확정한다.

```json
{
  "schema": "veilpoint-pc-build-v1",
  "source_sha": "3e984064fd740b5bfd3c68bcc30296c72c508600",
  "operation": "author-package"
}
```

## 자동 검증과 결과 확인

| 순서 | 작업 | 확인할 결과 |
| --- | --- | --- |
| 1 | UE5.8 저작·빌드 | 기본 맵 `CH01_Aden`을 다시 열어 확인. 패키지의 `BUILD_INFO.json`과 실행 기록의 소스 SHA가 요청과 일치. |
| 2 | 아덴 지면·충돌·지도 | 서쪽 1.024km 연속 보행 스윕, 지표·건물 경계 충돌, 현장·광역 지도와 최대 확대의 잘림 확인. 지면·서쪽 접속부·지도 캡처 확인. |
| 3 | 스토리·오프닝 | 17컷 PNG와 300초 타임라인, 음원 포함 여부, 컷신 입력 차단과 CH01 조작 전환 확인. 두 대표 분기를 CH12까지 진행하며 교전과 저장·복구 검사. 첫 캡처에서 **아덴, 예멘 남부 \| 2015년** 자막 읽기. |
| 4 | 창 모드·배틀로얄 | 별도 창 모드 렌더 검사. 로컬 호스트·클라이언트가 준비 상태와 경기 종료를 거치는지, 경기 중 이탈과 카운트다운 중 이탈 후 재접속이 처리되는지 확인. |
| 5 | 증거 정리 | `native-job.json`, `AdenSmoke/visual-smoke.json`, 대표 PNG, BR 호스트·클라이언트 로그를 대조한다. 아덴 후보와 전체 검증을 통과한 패키지의 경로와 SHA를 기록한다. |

실패하면 첫 실패 단계와 로그를 확인한다. 같은 원인으로 반복 실행하기 전에 소스나 실행기에서 원인을 해결한다. 기존 패키지와 저장은 복구와 성능 비교에 쓸 수 있도록 보관한다. [실행기와 로그 경로](GAME_DEV_TOOLCHAIN.md#네이티브-패키지-조작과-화면-검사)

## 패키지가 나온 뒤 직접 확인할 것

1. 검증된 새 패키지의 `PLAY_VEILPOINT.cmd`로 실행한다. 기존 저장을 옮기기 전에 첫 화면부터 한 번 재생한다. **이수혁 독백의 발음과 자막 싱크, 음량, ESC 일시 정지·재개, 배에서 내린 뒤 마우스와 WASD가 바로 동작하는 순간**을 확인한다. 자동 오프스크린 검사는 음소거 상태이므로 청취 검사는 직접 한다.
2. CH01에서 F 상호작용과 F7 체크포인트 복귀를 시험한다. **M → 현장 지도 → 휠 최대 확대**에서 목표 화살표가 읽히는지 확인한다. 지도를 닫은 뒤 벽과 보행 경계, 두 갈림길에서 화면과 충돌이 어긋나는 곳이 있으면 기록한다.
3. **RTX 3070과 2560×1440**으로 이전 패키지와 새 패키지의 같은 보행 구간을 비교한다. 두 패키지에서 그래픽 프리셋, 렌더 비율, FPS 제한과 V-Sync를 동일하게 설정한다. 첫 로딩이 안정되면 게임 화면에서 각각 **F9로 120초** 기록한다. 비교 구간에는 컷신·지도·메뉴를 넣지 않는다. `Windows/Veilpoint/Saved/Benchmarks`의 JSON 두 개로 평균 FPS와 p95·p99 프레임 시간을 비교한다. [F9 측정 기준](UE5_F9_NATIVE_APPLICATION_FRAME_BENCHMARK.md)

키보드·마우스와 청취 확인, F9 측정 결과는 자동 패키지 검사와 별도로 기록한다. BR의 로컬 검증 결과는 실제 인터넷 참가자와의 대전 결과와 구분한다.
