# VEILPOINT Windows 검증 대기 목록

## 빌드 대상

- 직전 Windows 성공본은 `95b9d8d7840d8045a5c5898ceec015a866c852f7`이다. 이 패키지는 아덴 보행과 기능 회귀를 확인할 때 사용한다.
- 이번 빌드 대상은 `b33f56ea758f226f9b7aabe1677a01a881a23741`이다. 기존 아덴 충돌 구역, 12장 연결, 5분 오프닝, 총기 시제품, 젖은 지면과 저장 복구 검증을 포함한다. 현장 지도 이동과 복귀, 지면 발소리, 최근 교신 기록, 발사·명중 표시, 배틀로얄 엄폐와 준비 상태 변경도 같은 패키지에서 확인한다.
- **상태는 시작 지시 대기.** PC에서 실행기 창이 닫혀 있다면 `START_BUILD_PC.cmd`로 연다. 처음 보이는 `Listening for Jobs`와 전용 저장소 Actions의 활성 작업을 확인한다. 이미 진행 중인 작업은 종료 결과부터 확인한다.

시작 지시가 오면 아래 요청으로 전용 Windows 실행기에 `author-package` 한 건을 넣는다. 이 작업에서 사전 점검, C++ 컴파일, 레벨 저작, 패키징과 실행 검사를 차례대로 수행한다. 실행 전 게임 저장소 `main`이 앞섰다면 이 기준점 이후의 변경을 먼저 확인해 빌드 대상을 확정한다.

```json
{
  "schema": "veilpoint-pc-build-v1",
  "source_sha": "b33f56ea758f226f9b7aabe1677a01a881a23741",
  "operation": "author-package"
}
```

실패하면 첫 실패 단계와 로그를 확인한다. 같은 원인으로 반복 실행하기 전에 소스나 실행기에서 원인을 해결한다. 기존 패키지와 저장은 복구와 기능 회귀 확인에 쓸 수 있도록 보관한다. [실행기와 로그 경로](GAME_DEV_TOOLCHAIN.md#네이티브-패키지-조작과-화면-검사)

## 패키지가 나온 뒤 직접 확인할 것

1. 검증된 새 패키지의 `PLAY_VEILPOINT.cmd`로 실행한다. 기존 저장을 옮기기 전에 첫 화면부터 한 번 재생한다. **이수혁 독백의 발음과 자막 싱크, 음량, ESC 일시 정지·재개, 배에서 내린 뒤 마우스와 WASD가 바로 동작하는 순간**을 확인한다. 자동 오프스크린 검사는 음소거 상태이므로 청취 검사는 직접 한다.
2. CH01에서 F 상호작용과 F7 복귀를 시험한다. **M → 현장 지도 → 휠 최대 확대**에서 화살표가 읽히는지, 방향키로 이동한 다음 Home으로 돌아오는지 확인한다. 지도에서 WASD와 마우스를 써도 1인칭 위치·시야가 유지되는지, 실제 지면에서 걸을 때 발소리가 나는지 확인한다. J를 열어 방금 지나간 교신을 다시 읽는다.
3. CH02 교전에서 **R 재장전 타이머와 탄약 표시**를 확인한다. 탄약을 가진 상태에서 빈 탄창과 탄이 남은 탄창을 각각 재장전하고, 연속으로 발사했을 때 과열 안내가 나타났다 냉각 뒤 사라지는지 확인한다.
4. 배틀로얄 로컬 호스트·클라이언트에서 직접 보이는 상대와 벽 뒤에 있는 상대를 비교한다. 벽이 막으면 피해나 X 명중 표시가 발생하지 않는지 확인한다.

키보드·마우스와 청취 확인은 자동 패키지 검사와 별도로 기록한다. BR의 로컬 검증 결과는 실제 인터넷 참가자와의 대전 결과와 구분한다.
