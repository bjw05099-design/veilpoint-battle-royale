최신 CH01 서사는 [CH01_SCREENPLAY_KO.md](CH01_SCREENPLAY_KO.md), 사실 근거는 [CH01_HISTORY_SOURCES.md](CH01_HISTORY_SOURCES.md)다. `narrative/ch01-scene-plan.json`은 제작용 장면·원인·결과 데이터이며 브라우저나 UE 런타임에 아직 연결되지 않았다.

## 장면·세이브 요구사항

- 기존 V2를 새 50분 장의 진행도로 해석하지 않는다. 새 장 상태는 별도 버전과 명시적 이전 정책을 정한다.
- 구형 ID `mara-dahan`, `yusuf-rahal`은 호환용 식별자일 수 있다. 화면 이름과 저장 ID를 구분한다.
- 체크포인트는 CP01 준비 완료, CP02 연락실 탈출, CP03 현장 협의, CP04 승차, CP05 구호소 접근, CP06 장 종료다. 각 지점의 동행·물품·차량·문·대사 상태를 함께 복원한다.
- `evacuation`과 `verification`의 구형 선택값은 보존 가능하지만 기존 프리뷰 완료를 새 구호소 도착으로 간주하지 않는다.
- 선택 탐색 생략 시 주 경로를 차단하지 않는다. 전투·운반·동행 시간이 겹칠 때 주 활동 하나만 계측한다.
- CH02를 만들거나 플레이 가능으로 잠금 해제하지 않는다. BR 상태·점수·세이브로 이야기를 유출하지 않는다.

## 제작 검증 순서

1. **문서:** 14장면 합계 50분, 중복 없는 활동 예산, 원인·결과 참조, 이름 표기와 날짜, 후대 사건 제거. 이번 회차 검증 범위.
2. **고증/대본:** 예멘 역사·아덴 방언 감수, 독립 독자의 인물 동기·감정·설명 과잉 검토. 미실시.
3. **회색박스:** 실제 거리·문·차량 좌석·동행 통행·전투 종료 조건·분기 합류. 미실시.
4. **연출:** 원어 연기·자막·공간 음향·모션·사물의 앞뒤 연속성. 미실시.
5. **실행:** 기존 필수 Node·브라우저·패키지 CI 및 Windows/UE 실기동·초회 플레이테스트. 이 문서 회차에서 실행 완료를 주장하지 않는다.

대본 패치의 자동 검증은 시간표·데이터 참조 같은 구조적 누락만 찾는다. 역사적 진실, 현지 이름의 자연스러움, 감동, 50분 실측 시간을 증명하지 않는다.
