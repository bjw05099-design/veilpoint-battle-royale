## 배틀로얄 개발 검증

Development 빌드의 BR_Development는 분리된 기존 합성 시험 환경이다.
준비 로비에서는 들어온 플레이어들이 Enter로 준비를 확인한 뒤 게임이
시작된다. 게임 시작 후에는 기존 경기의 참가 인원이 고정된다.
로비에는 서버 정보를 기준으로 참가자 대기, 준비 대기, 카운트다운,
경기 시작 확인이 구분되어 표시된다.
종료 화면은 서버가 기록한 결과와 경기 시간을 표시한다.

Windows 자동 검사는 로컬 루프백에서 실제 Unreal 프로세스 두 개로
호스트와 클라이언트를 실행한다. 두 플레이어가 준비할 때까지 경기
시작이 보류되는지, 종료 후 각 이동 기록이 소유자에게만 전달되는지
확인한다. 배틀로얄 공개 출시와 96인 인터넷 대전에는 별도 검증이 필요하다.
경기 시작 시 서버에서 참가 명단을 고정하고 연결을 종료한 참가자를
생존 집계에서 제거한다. 별도의 루프백 경기에서 진행 중 클라이언트가
종료했을 때 남은 호스트의 1위와 이동 기록 확정을 검사한다.
경기 전 카운트다운 도중 클라이언트가 이탈하는 경우도 검사한다. 서버는
카운트다운을 취소하고, 재입장한 플레이어가 준비를 누르고 두 명이 준비된
뒤에 새 카운트다운을 시작해야 한다.
