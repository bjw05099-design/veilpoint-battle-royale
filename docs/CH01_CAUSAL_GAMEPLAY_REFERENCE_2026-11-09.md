# VEILPOINT 스토리 모드 — 게임플레이 영상 분석 적용 명세 (2026-11-09)

> **근거와 한계:** 프로젝트 소유자가 제공한 약 14분 18초 분량 게임플레이 화면 분석(전체 5초 간격, 주요 구간 2초 간격 확인)을 참고한 **2차 분석 입력**이다. 이 문서 작성 도구가 영상의 전 프레임·오디오를 독립적으로 재검증한 것은 아니다. 오디오 품질·동작 프레임·플레이 자유도·AI의 실제 자율성에 대한 확정 판단은 보류한다. 5시간 분량의 유튜브 영상 전체에 대한 분석이 아니다.
>
> **목표:** 특정 타 작품의 장면/대사/지도/미션을 재현하는 것이 아니라, **이전의 사건과 인물 행동이 다음 플레이어 행동의 납득 가능한 이유를 만든다**는 장면 설계 원리를 VEILPOINT 고유 세계에 구현한다.
>
> **상위 규칙:** [Combat Campaign Canon](COMBAT_CAMPAIGN_CANON.md), [2015년 서사 기준](VEILPOINT_STORY_HISTORICAL_DRAMA_KO.md), [아덴 지형 참고](WORLD_REFERENCE_ADEN.md), [몰입 품질 기준](CAMPAIGN_IMMERSION_STANDARD.md). 이 문서는 실제 구현·통과 검증 기록이 아니라 작업 요구사항이다.

## 1. 변경할 수 없는 이야기의 전제

- 이수혁 대위는 **한국에서 출국 전에** 정식 파견 지시, 비전투 성격의 현지 민간 통신 협력·구호 지원 임무와 복귀 계획을 수령하고 브리핑을 마쳤다. 현지에서 지시서를 찾아 정체를 알아내는 전개는 금지.
- 2015년 아덴의 역사적 도시·항구·건축·문화는 **장면 설계의 현실적 참고**이며, 주 무대는 독자적 가상 항구 도시 나흐린이다. 실제 주민의 비극·실제 전투 현장을 특정하게 재현한다고 주장하지 않는다.
- 원래 임무를 수행 중이던 현지에서 **예기치 못한 내전 확대**가 발생한다. 첫 사건은 도시·민간인·동료의 행동과 후속 임무 우선순위를 바꾸어야 한다.
- 12시간/720분은 목표 분량이지 측정된 결과가 아니다. 전체 목표 비중은 **전투 50% / 긴박한 이동·구조 20% / 인물·서사 22% / 탐색·상호작용 8%**.
- 김지윤·조현지·유수프·마라·나딤은 독립적인 지식, 동기, 이동 가능한 위치 및 권한을 가진다. 현지 이동·구조의 판단과 승인은 현지 당사자의 몫이다.

## 2. 장면을 조립하는 최소 단위: 인과 연쇄

모든 주요 플레이 시퀀스를 아래 8개 필드로 기획하고, 코드와 테스트도 같은 순서로 검증한다.

| 항목 | 반드시 구체화할 질문 | 구현 증거 |
|---|---|---|
| 직전 원인 | 플레이어가 **이미 목격했거나 알게 된** 무엇 때문에 이번 행동이 필요한가? | 직전 사건의 world-state 변수/로그 |
| 인물 동기 | 지금 이수혁과 현지 인물은 각각 무엇을 원하고, 무엇을 모르는가? | 대사·행동의 정보 출처와 권한 |
| 플레이어 행동 | 움직임/관찰/상호작용/도움/선택 중 실제로 조작할 것은? | 입력과 도달 가능한 물리 지점 |
| 감각 단서 | 조명, 시야, 주민 행동, 환경 변화가 **어떤 순서로** 상황을 알리는가? | 가시 지오메트리·환경 상태 |
| 즉각 반응 | 행동 이후 인물·공간·목표 중 무엇이 실제 바뀌는가? | 상태·충돌·애니메이션 전이 |
| 뒤따르는 이유 | 새로운 상황이 다음 이동/판단/임무를 **왜** 요구하는가? | 다음 목표의 정당화 조건 |
| 지속성 | 지나간 피해·위치·연락·이동·소모가 나중에도 남는가? | 세이브·로드 전후 동일한 결과 |
| 우회 경로 | 멈추거나 다른 방향으로 가거나 스킵하면 플레이가 계속 가능한가? | 입력 이탈·재진입·복구 테스트 |

“출구에 도착 → 이벤트 → 다음 마커로 이동”만 반복한다면 인과 연쇄를 통과하지 못한다. 이벤트가 **다음 행동의 이유**를 만들어야 한다.

## 3. CH01 플레이 가능한 도입부의 원안 (영상 장면 복제 금지)

**상태 A · 도착 후 기존 업무:** 항구 구역의 공공 통로와 민간 통신 협력 장소에 정상적인 활동이 존재한다. 인물이 실제 위치를 점유하고 일에 몰두하며, 이수혁이 이동하는 동안 자기들끼리 짧게 대화한다. 플레이어는 관찰, 동행, 현장 확인 같은 작은 행동을 직접 수행한다. 한국 출국 전 브리핑은 짧은 회상/대사로 이미 끝난 사실만 확인한다.

**상태 B · 익숙해진 소규모 공간:** 한두 곳의 접근 가능한 상점 앞·공공 대기 공간·항구 설비에서 자연스러운 물건/사람 접촉을 제공한다. *어떤 물건이든 E로 조사하는 수집품 루프*는 금지. 시민은 진열, 운반, 대화, 이동 등 도시와 직접 관련된 행동을 한다. 단순한 현지 관광이나 이유 없는 물품 구입 장면을 추가하지 않는다.

**상태 C · 조용한 이상 징후:** 정상 활동의 일부가 점진적으로 달라진다. 예를 들어 주변 통신 불안정이나 전력 변동에 대해 주민과 현지 담당자가 서로 다른 수준으로 반응한다. **원인을 단정하지 않고**, 먼저 감각적 변화를 목격하고 그다음 인물 반응을 보게 한다. 모든 설명을 즉시 무전으로 전달하지 않는다.

**상태 D · 사건과 행동 목적의 전환:** 충돌 확대가 현지에 영향을 미친 뒤 이동 가능한 경로, 일부 활동, 동료의 몸짓과 단기 목적이 변한다. 피해를 선정적으로 표현하지 않는다. 플레이어가 상황을 파악하고 현지 담당자와 물리적으로 접촉할 수 있어야 하며, 장면이 끝난 다음 즉시 평시 상태로 복귀하지 않는다.

**상태 E · 이동/짧은 재정비/다음 국면:** 넓은 거리 → 접근 가능한 실내 → 시야가 제한된 연결 공간 → 다시 다른 성격의 열린 공공 구역 등 공간 규모를 변화시키되, 경로는 실제 지형으로 연결한다. 안전해 보이는 곳에서도 일행의 상태를 확인하고, 새로운 길이나 목표는 현장 상황이 결정한다. 다음 전투/위험 구간 역시 이전 상황의 결과여야 한다.

**중요:** A~E는 **구현 제안**이며 현재 CH01 브라우저 데모가 이 모든 내용을 갖추었다는 뜻이 아니다. 기존 CH01 임무와 충돌하는 신규 의무 수집·서류 확인·의미 없는 대기·투표/집결 시스템을 만들지 않는다.

## 4. 동료를 행동하는 인물로 만드는 기준

1. **비대상 대화:** 김지윤과 조현지, 그리고 현지 인물은 플레이어의 입력이 없어도 짧게 서로 반응할 수 있다. 관련 없는 반복 대사로 화면을 채우지 않는다.
2. **공간적 연속성:** 동료가 멈춤/고개 회전/걷기/거리 유지/사람 지나갈 때 비켜섬/대피 중 자세 바꿈 등의 상태를 보여준다. 위치가 플레이어 카메라 밖에서 순간이동하지 않는다.
3. **상황 변화 인지:** 놀람, 동료 상태 확인, 신속한 이동, 잠깐의 재정비가 **실제 사건과 연결**된다. 플레이어보다 멀리 떨어진 사건을 무근거로 먼저 안다고 말하지 않는다.
4. **물리적 도움:** 중요한 순간의 손짓, 문 통과, 근거리 확인 등의 애니메이션은 캡션만 뜨는 연출이 아니라 일정한 위치와 물리적 조건을 갖는다. 플레이어의 입력을 가능한 한 유지한다.
5. **연출과 AI 구별:** 정해진 컷의 시각적 설득력과, 플레이어가 다른 방향으로 갔을 때의 동료 길찾기·복구 능력을 **서로 다른 테스트**로 측정한다.

## 5. 공유 도시: 아름다운 건물보다 '살아 있는 장소의 변화'

- 도시의 초기 상태를 시민 이동·상점 앞 작업·정박 시설·골목 조명·교통 흐름으로 보여준다. 역사적/문화적 정확성은 공개적인 도시 자료를 기준으로 검증한다.
- **같은 공간을 다른 상태로 다시 경험**하도록 한다. 평상시에는 생활과 이동을 보여 준 건물·거리·공공 시설이 사건 뒤에는 접근성, 활동, 빛, 분위기가 달라진다.
- 광장/시장/항만/복도/실내/지하 시설에서 시야와 이동 방식이 달라지더라도 **물리적 연결 및 보행 가능한 통로**를 일관되게 유지한다.
- 가시 메시(mesh)와 실제 이동 충돌이 일치해야 하며, 카메라 높이·근거리 손 애니메이션·장면별 조명이 플레이어 현재 동작을 설명해야 한다.
- 신규 건물을 늘리기 전에 최소 1개 구역에서 **평시→이상→사건 후의 시각적/행동적 상태 변화**를 검증한다.
- 도시·실내·외부의 음향 변화(잔향, 음성 거리, 외부/내부 전환)는 **향후 구현/청취 검증 항목**이지 영상에서 확인된 장점으로 취급하지 않는다.

## 6. 제작 우선순위와 명확한 완료 조건

| 단계 | 우선 구현 | 자동/수동 검증 |
|---|---|---|
| P0 | 현장 내 플레이 가능한 도입 행동 → 인물 반응 → 상태 변화 → 새 목적의 연결 한 세트 | 첫 사건 이전·이후 목표가 다른 이유로 제시되는지, 중도 입력/로드가 안전한지 |
| P1 | 시민 1~2명 및 동료 1~2명의 실제 이동/작업·사건 반응 | 도착/회피/거리/멈춤, 스킵 시 결과, 보이지 않는 순간이동 없음 |
| P1 | 동일 거리의 평시/사건 후 변형과 접근 가능한 실내 | 충돌·시각 동일성, 두 상태에서 이동 가능한 실제 통로 |
| P2 | 신체 근접 상호작용, 시점 상태, 점진적 밝기 변화, 보조 자막 | 과도한 시점 흔들림 제거/감소 설정, UI·입력 유지 |
| P2 | 공간에 따른 동료 대사·환경음·동작 블렌딩 | 실제 청취/브라우저 화면 캡처/UE5 빌드에서 별도 검증 |

**실패 판정:** 이유 없는 강제 목표 변경, 플레이어를 막는 동료, 영상 컷 사이 위치 점프, 이동이 불가능한 실내, 지나간 사건의 흔적 삭제, 실제 확인하지 않은 구조 완료 선언, 대사만 바뀌는 가짜 선택, 원본 게임의 인상적인 장면/대사/순서를 그대로 옮기는 연출.

## 7. 개발/보고 시 표기

- **참고·설계** ≠ **코드 구현** ≠ **자동 테스트 통과** ≠ **실제 플레이 검증** ≠ **실제 오디오 검증** ≠ **UE5 빌드**.
- 모든 실질적 개발 회차는 장면의 시각 결과뿐 아니라 **원인과 다음 행동의 인과**, 동료/도시 상태 지속성, 저장/복구를 보고한다.
- 단일 장치(대화/수집품/차양/셔터 등)를 반복하는 대신 스토리·도시·동료·이동·상호작용·연출을 분산해 진척시킨다.
- 참고 영상의 관찰 요약은 사용자 제공 자료로 출처를 밝히고, 직접 청취하지 않은 소리나 미확인 조작 자유도를 구현 사실처럼 말하지 않는다.
